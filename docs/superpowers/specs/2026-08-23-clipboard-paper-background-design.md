# Word Journal 夹板纸背景设计

## 目标

为 Word Journal 建立更明确的手账视觉记忆点，同时保持学习页面安静、易读、不花哨。今日首页采用用户确认的 A「完整夹板」构图；其他页面只延续纸张纹理，不展示完整金属夹。

## 最终视觉

- 生成一张适合桌面网页的横向高分辨率位图，目标尺寸为 2048×1152。
- 画面使用深灰褐桌面背景，中央放置一张大面积米白手工纸，顶部居中为低饱和古铜色金属夹。
- 纸张必须具有真实可见但低对比度的纤维纹理、轻微色差和自然毛边；纹理来自图片本身，不用 CSS 噪点、渐变或程序纹理模拟。
- 图片内不出现文字、按钮、线条、图标、水印或其他装饰物。
- 纸面中央保留充足、均匀、低干扰的内容安全区；金属夹不遮挡导航和首页标题。
- 光照柔和、阴影克制，整体延续现有苔绿色、暖纸色与灰褐色系统。

## 页面应用

### 今日首页

- 完整背景图覆盖主要视口，夹子保持顶部居中，纸张承载首页标题、进度、List 列表和录入入口。
- 桌面端优先完整展示夹子与纸张边缘；超宽屏允许露出更多桌面背景。
- 移动端以夹子中心和纸面内容安全区为裁切锚点，允许左右纸边被裁掉，不允许正文落到深色桌面区域。

### 录入、复习、历史和设置页

- 复用同一张图片的纸面区域作为低干扰背景，不显示完整夹子。
- 页面内容继续使用现有布局和交互层级，不新增装饰卡片或分割线。

## 实现边界

- 最终图片保存到项目 `public/assets/`，由 CSS 以背景资源引用。
- CSS 只处理 `background-image`、尺寸、位置、裁切和必要的可读性底色，不生成纸张纹理或夹子造型。
- 保留纯色背景作为图片加载失败时的回退。
- 图片需要压缩到合理体积，避免明显拖慢首次加载；不牺牲纸纹和毛边观感。

## 验收标准

- 375px、768px 和 1440px 宽度下无水平滚动，首页正文始终位于浅色纸面。
- 导航、标题、按钮和状态文字达到 WCAG AA 对比度，焦点样式清晰。
- 背景不会随内容滚动产生突兀拼接，也不会出现重复平铺。
- `prefers-reduced-motion` 下没有额外背景动画。
- 现有单元测试、类型检查、生产构建和 Playwright 浏览器测试继续通过。
