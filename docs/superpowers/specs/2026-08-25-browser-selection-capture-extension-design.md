# Word Journal 浏览器划词收录扩展设计

日期：2026-08-25  
状态：已确认

## 1. 背景与目标

Word Journal 当前是英语单词与短语的本地学习、复习工具。本阶段将完整产品打包为 Chrome / Edge Manifest V3 扩展，并增加网页划词收录能力，用最少操作完成“看到内容—补全释义—进入复习系统”的闭环。

MVP 的核心目标：

- 用户不打开 Word Journal 主页面，也能在普通网页划取英文单词或短语。
- 划词后先预览 AI 补全结果，由用户确认后收录。
- 所有学习数据和用户 API Key 均保存在扩展本地，不要求登录或启动本地服务器。
- 浏览器采集能力与学习业务解耦，为未来桌面全局划词预留稳定接口。

## 2. MVP 范围

### 2.1 包含

- Chrome 与 Edge 共用一套 Manifest V3 扩展代码和构建产物。
- 点击扩展图标，在新标签页打开或聚焦完整 Word Journal 页面。
- 在普通 HTTP / HTTPS 网页中选择英文单词或最多 8 个英文单词的短语。
- 选区附近显示轻量入口，点击后展示确认预览。
- 通过用户配置的 OpenAI-compatible API 补全中文释义和一个常见例句。
- 预览内容可编辑，确认后进入待整理队列。
- 本地重复检测，并允许用户明确选择再次加入。
- 完成当日复习后，将待整理内容批量生成新的 List。
- 保留现有发音、表格复习、单词复习、历史复习和遗忘曲线能力。

### 2.2 不包含

- 句子收录；超过 8 个英文单词的内容不发送给 AI。
- 截图、图片识别、粘贴任意知识内容或通用知识卡片。
- 桌面系统全局划词。
- 登录、云同步、多设备共享或团队协作。
- 网页来源、标题、URL、周围上下文或浏览历史的保存。
- 项目方托管的 AI 代理或公共 API Key。

## 3. 产品规则

### 3.1 主界面打开方式

扩展工具栏图标打开完整的新标签页。若 Word Journal 标签页已经存在，则聚焦该标签页，不重复创建。主标签页是否打开不影响网页划词能力。

### 3.2 可收录内容

内容必须满足以下条件：

- 选择内容去除首尾空白后非空。
- 由英文单词及常见英文标点构成。
- 单词数为 1 至 8。

一个单词标记为 `word`，两个至八个单词标记为 `phrase`。非英文内容不显示入口；超过八个单词时，不调用 AI，并提示当前版本暂不支持句子。

### 3.3 当日学习门槛

所有网页划词确认结果先进入“待整理”。当日待复习内容未完成时，仅展示待整理数量，不允许据此开始新的学习 List。完成当日复习后，用户进入待整理页，批量检查并一次性生成新的 List。该规则保持“先完成当日复习，再进入下一批学习”的产品约束。

### 3.4 重复内容

查重使用标准化英文值：统一大小写、去除首尾空白并合并连续空格。发现已有记录时，预览显示原 List，默认不重复添加，同时提供视觉优先级较低的“再次加入”。用户明确选择后创建新的学习记录。

## 4. 系统架构

### 4.1 扩展模块

- **New Tab App**：承载现有 React 学习界面、历史、设置与待整理页面。
- **Content Script**：读取用户明确选择的文本，控制轻量入口和确认浮层。
- **Service Worker**：处理消息、AI 请求、校验、查重、持久化和主页面调度。
- **Capture Core**：与浏览器 API 解耦的校验、标准化、补全、查重和收录流程。
- **Local Repository**：封装 IndexedDB，不让 UI 或采集层直接依赖数据库实现。
- **Extension Settings**：管理 AI 地址、模型、API Key 与划词功能开关。

### 4.2 稳定接口

```text
CaptureAdapter
  ├─ BrowserSelectionAdapter
  └─ FutureDesktopSelectionAdapter

CaptureService
  ├─ validate()
  ├─ enrich()
  ├─ detectDuplicate()
  └─ saveToInbox()

LearningRepository
  ├─ IndexedDbRepository
  └─ FutureSyncRepository
```

浏览器与未来桌面程序只负责产生统一的 `CaptureDraft`。AI 补全、重复检测、List 生成和遗忘曲线逻辑不感知采集来源。

### 4.3 CaptureDraft

```ts
interface CaptureDraft {
  id: string;
  text: string;
  normalizedText: string;
  type: "word" | "phrase";
  chineseMeanings: string[];
  example: string;
  status: "enriching" | "ready" | "saved" | "failed";
  capturedAt: string;
}
```

数据中不包含来源网站、标题、URL、上下文或浏览记录。

## 5. 用户交互

### 5.1 划词入口

用户选择符合条件的英文内容后，在选区附近出现低干扰的 Word Journal 小按钮。取消选择、滚动页面或点击空白区域时，按钮自动关闭。系统不在用户仅仅选择文字时自动请求 AI。

右键菜单提供备用的“收录到 Word Journal”入口，用于轻量按钮不便操作的场景。

### 5.2 确认预览

点击入口后才发起补全，并显示：

- 原始英文内容；
- 单词或短语类型；
- 完整中文释义；
- 一个常见意思对应的英文例句；
- 可编辑的中文释义与例句；
- 主操作“加入待整理”和次操作“取消”。

AI 请求失败时保留当前选词并提供重试，不创建半成品记录。未配置 API Key 时引导用户打开设置页；配置完成后用户可回到原页面重新触发。

## 6. 本地存储

IndexedDB 保存：

- `captureDrafts`：待整理内容及处理状态；
- `entries`：英文、类型、音标、中文释义与例句；
- `lists`：每天形成的学习 List；
- `reviewSchedules`：遗忘曲线日期与完成状态；
- `reviewSessions`：历史复习记录。

`chrome.storage.local` 保存：

- AI API 地址；
- 模型名称；
- 用户自己的 API Key；
- 划词功能开关。

API Key 不写入源码、IndexedDB 或版本库。`chrome.storage.local` 不是系统级保险箱，因此 MVP 定位为个人设备使用；公开发行时必须重新评估服务端代理与密钥管理。

## 7. 权限与隐私

申请最少必要权限：

- `storage`：扩展设置与本地状态；
- `scripting`：网页采集脚本；
- `contextMenus`：右键备用入口；
- `tabs`：打开或聚焦完整主页面；
- `host_permissions`：仅 `http://*/*` 和 `https://*/*`。

默认不启用无痕模式，不读取浏览历史。`chrome://`、`edge://`、扩展商店及其他禁止脚本注入的页面不支持划词，并向用户提供明确的平台限制提示。

只有用户点击划词入口后，明确选择的文本才会发送给其配置的 AI 服务。扩展不采集或发送网页上下文。

## 8. 异常恢复

- 断网、超时或 AI 格式异常：保留选词，显示可理解错误并允许重试。
- Service Worker 被浏览器回收：从持久化数据恢复队列和状态。
- IndexedDB 写入失败：不显示收录成功，不丢弃当前预览。
- Word Journal 标签页已存在：聚焦现有页面。
- 用户关闭划词开关：停止显示网页入口，已有数据及复习能力不受影响。
- 受限页面无法注入：右键或界面提示该页面不受浏览器扩展支持，不伪报成功。

## 9. 验收标准

- 主页面未打开时，普通网页仍可收录英文单词或最多八词短语。
- 选择中文、空白或超过八词的内容不会发起 AI 请求。
- AI 结果能够预览、编辑、确认并进入待整理。
- 数据中不存在来源 URL、网页标题或上下文。
- 重复内容能够识别，且只有用户明确选择时才再次加入。
- 未完成当日复习时，待整理内容不会生成新 List。
- 关闭并重启浏览器后，待整理、List 和复习进度仍存在。
- 点击扩展图标只打开或聚焦一个完整主页面。
- 不启动现有 Node 服务，也能完成划词、AI 补全和本地保存。
- Chrome 与 Edge 使用同一套 Manifest V3 源码和构建流程。
- 现有发音、表格模式、单词模式、历史复习和遗忘曲线行为不回归。

## 10. 测试策略

- **单元测试**：文本校验、八词边界、标准化、重复检测、状态转换和 List 门槛。
- **集成测试**：IndexedDB 持久化、Service Worker 消息、设置读取和失败恢复。
- **扩展端到端测试**：划词入口、确认浮层、待整理、主页面单实例打开。
- **回归测试**：现有学习与复习流程。
- **人工运行时验证**：Chrome、Edge、真实 AI API、受限页面提示、扩展安装后的发音。

构建或自动测试通过不等同于真实 API、浏览器权限、声音输出及人工视觉验收通过；交付时分别报告这些证据。

## 11. 后续演进

完成浏览器扩展 MVP 验证后，再独立设计桌面全局划词。桌面版本增加 `DesktopSelectionAdapter` 和系统权限层，复用 `CaptureDraft`、`CaptureService`、学习仓库接口及复习领域逻辑。

截图、粘贴文本、通用知识卡片和 AI 主题聚合属于后续独立阶段，不进入本次实现计划。
