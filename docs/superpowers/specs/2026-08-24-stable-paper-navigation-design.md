# 稳定纸张导航与首页进度位置设计

## 背景

首页与内页使用不同的 `.app-shell` 宽度，导致品牌、历史和设置入口在路由切换时横向移动。首页 Header 还有独立的半透明背景，与“导航直接落在纸张上”的目标不一致。今日进度目前靠近夹子并与其视觉区域重叠。

## 目标

- 所有页面的三个导航位置保持一致，路由切换时不移动。
- Header 默认直接显示在纸张区域上，不使用独立 Navbar 背景、卡片或常驻阴影。
- 鼠标进入整个 Header 区域时显示轻微暖灰绿色阴影，离开后淡出。
- 首页今日进度下移到夹子下方，同时保持居中和纸张安全宽度。
- 背景图片、导航内容、业务逻辑和内页内容宽度保持不变。

## 导航定位

- Header 使用独立于页面内容容器的统一视口宽度：`width: min(calc(100vw - 112px), 1400px)`。
- Header 相对当前 shell 水平居中，使用 `left: 50%` 与 `transform: translateX(-50%)`，因此首页和内页切换时位置不受 shell 宽度影响。
- 桌面端两侧视觉边距约 56px；大屏时最大宽度为 1400px。
- 820px 以下切换为 `width: calc(100vw - 40px)`，保持 20px 两侧边距并避免横向滚动。
- Header 高度、品牌与导航 DOM 顺序不变，点击区域继续不小于 44px。

## 默认视觉

- Header 背景完全透明。
- 默认不使用 `box-shadow`。
- 保留极淡底部分隔线，颜色采用低透明深灰绿色。
- 左侧为线性打开书本图标与 `Word Journal`；品牌继续使用优雅 Serif 字体。
- 右侧为“历史”、淡垂直分隔线和设置齿轮图标。
- 品牌、导航文字和图标统一使用深灰绿色，hover 与当前路由状态继续使用低饱和森林绿。

## Header Hover 反馈

- 鼠标进入整个 Header 区域后，仅增加底部扩散的轻阴影：`0 10px 28px rgb(45 49 40 / 7%)`。
- 阴影通过约 180ms 的 ease-out 过渡显示和隐藏。
- Hover 不增加背景色、边框容器、圆角或位移，避免形成卡片。
- 键盘焦点继续使用现有可见 focus ring，不依赖阴影表达状态。
- 触控设备没有 hover 时，Header 始终保持默认透明状态。

## 今日进度位置

- 保持 `.progress-wrap` 最大宽度 840px 并水平居中。
- 增加 `.today-progress` 顶部留白，使标签和轨道的第一行位于夹子视觉底部以下。
- 桌面端顶部留白使用响应式范围，目标约 88px 至 112px；底部留白保持克制。
- 820px 以下使用较小但明确的顶部留白，避免移动端首屏过度空旷。
- 不改变进度条高度、颜色、数值或移动端两行布局。

## 验收标准

- 首页、历史、设置和复习页的品牌、历史与设置入口横向位置一致。
- 路由切换时 Header 不发生横向跳动。
- Header 默认没有背景和阴影。
- 鼠标进入 Header 时出现轻微暖灰绿色阴影，离开后消失。
- Header 不呈现卡片、圆角或常驻色块。
- 今日进度位于夹子下方，标签、轨道和数字仍在纸张安全区内。
- 375px、768px、1440px 均无横向溢出。
- 背景图片哈希、内页内容宽度和业务逻辑不变。

## 非目标

- 不将 Header 设置为吸顶或固定定位。
- 不改变导航项目、图标、路由或文案。
- 不重新设计首页核心区域、按钮或连续学习信息。
