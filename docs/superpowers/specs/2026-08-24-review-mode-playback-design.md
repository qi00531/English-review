# 复习视图播放行为设计

## 背景

复习页包含单词模式与表格模式。播放按钮必须跟随当前视图的学习对象，避免用户在查看单个单词时意外启动整个 List。

## 目标行为

### 单词模式

- 进入单词模式后，自动循环播放当前单词。
- 切换到上一个或下一个单词时，停止旧单词并自动循环播放新单词。
- 播放按钮只控制当前单词：播放时显示暂停操作，暂停后显示播放操作。
- 用户暂停后，只有点击播放按钮、切换单词或重新进入单词模式才恢复播放。

### 表格模式

- 进入表格模式时不自动播放。
- 用户点击播放按钮后，从 List 第一个单词开始顺序播放；播放到末尾后从头继续循环。
- 用户再次点击按钮时停止整组循环。
- 点击某一行仍只播放该行一次，不启动整组循环。

### 模式切换

- 从单词模式切到表格模式时，立即停止当前单词，并保持表格模式静默。
- 从表格模式切到单词模式时，立即停止整组或单行播放，并自动循环当前选中的单词。
- 任一时刻只能存在一个活动音源。

## 状态与组件边界

`ReviewPage` 根据 `layout` 决定播放按钮的语义：

- `word`：按钮调用当前单词循环或 `pause`。
- `table`：按钮调用整个 List 循环或 `pause`。

页面维护统一的播放状态，用于呈现播放/暂停图标。`AudioController` 继续负责音源互斥、当前单词循环、整组循环与单行播放，不新增播放模式。

## 异常处理

- 字典音频缺失或加载失败时，继续降级到浏览器语音。
- 浏览器要求用户手势时，保留“点击页面开启发音”入口。
- 浏览器语音确实不可用时，保留“当前浏览器无法发音”提示。
- 播放失败后按钮必须显示为可播放状态，不能伪装成仍在播放。

## 验收标准

- 单词模式初次进入会循环当前单词。
- 单词模式点击暂停后停止；再次点击只恢复当前单词。
- 单词翻页会停止旧单词并循环新单词。
- 表格模式初次进入不自动播放。
- 表格模式点击播放后循环整个 List，再次点击停止。
- 表格行点击只播放该词一次。
- 两种模式切换不会产生重叠音频。
- 发音恢复提示与失败状态仍能正确工作。

## 非目标

- 不增加第二个播放按钮。
- 不改变页面布局、视觉样式或发音来源。
- 不保存播放状态到数据库；刷新页面后按当前模式的默认规则执行。
