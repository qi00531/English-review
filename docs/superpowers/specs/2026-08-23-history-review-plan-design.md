# 历史手动复习与复习计划一览设计

## 目标

在现有「历史」页中增加两项能力：

1. 用户可从历史 List 手动进入复习模式。
2. 用户可按日期查看全部艾宾浩斯复习安排，例如「8 月 24 日：List 1、List 2」。

设计延续当前简洁手账风，优先呈现学习任务，不把历史页做成数据仪表盘。

## 页面结构

历史页顶部使用两个轻量文字标签：

- `复习计划`
- `全部 Lists`

标签不使用厚重按钮、卡片容器或强边框。「复习计划」是进入历史页时的默认标签。

### 复习计划

- 展示数据库中从最早到最晚的全部复习日期。
- 进入页面时自动定位到今天；如果今天没有计划，定位到今天之后最近的日期；如果没有未来计划，定位到最后一个日期。
- 每个日期将当天需要复习的 Lists 聚合展示。
- 同一日期中的 Lists 按 `listNumber` 升序排列。
- 同一 List 在同一日期异常出现多个节点时，界面只展示一次。

日期状态：

- `已完成`：该日期下的所有复习节点都已完成。
- `待复习`：日期为今天，且至少一个节点未完成。
- `已逾期`：日期早于今天，且至少一个节点未完成。
- `未开始`：日期晚于今天。

今天与已逾期日期中的 List 可直接进入正式复习。未来日期仅展示计划，不提供提前完成入口。已完成日期的 List 可作为额外复习进入，但不再修改计划状态。

### 全部 Lists

- 保留现有按 List 编号倒序展示、展开词条、编辑词条与删除 List 的能力。
- 每个 List 增加明确的「开始复习 →」入口。
- 复习入口与删除操作保持足够间距，避免误触。

## 手动复习规则

从历史页进入复习时携带来源信息，用于区分今日任务与手动复习。

- 如果该 List 在今天有已到期且未完成的节点，完成整个 List 后同步完成该节点。
- 如果今天没有已到期节点，该次为额外复习，不修改任何历史或未来复习节点。
- 完成时重新从数据库查询今天可完成的节点，不依赖进入页面时的旧快照。
- 从历史进入的复习结束后返回 `/history`，并恢复进入时的标签。
- 从首页今日任务进入的复习仍返回首页。
- 手动额外复习不能解锁今日新 List 录入；现有「当天到期内容必须全部完成」的规则保持不变。

## 数据与模块边界

- 不新增数据库表，不修改现有 Schema，不需要数据迁移。
- 复习计划一览直接使用现有 `reviewNodes`，按 `dueDate` 聚合并关联 Lists。
- 新增独立纯函数负责计划分组、排序、去重和状态计算，避免将领域逻辑堆入 React 组件。
- 历史路由继续使用 Dexie `liveQuery`，复习完成后状态自动刷新。
- 复习路由解析来源参数，并在完成时按最新数据决定是否完成今天的节点。

## 异常处理

- List 不存在或已被删除：显示明确空状态和返回历史页入口，不无限显示加载状态。
- List 没有词条：保留空状态并允许返回历史页。
- 复习节点无法关联 List：一览界面跳过该异常项，但不删除原始数据。
- 页面订阅数据变更，防止手动复习与计划状态不同步。

## 视觉与可用性

- 保留现有纸张背景图，不更换、不重新生成。
- 标签使用文字、底线或轻量颜色变化表达选中态。
- 计划使用线性日期列表，不使用卡片网格或数据 Dashboard。
- 状态依靠文字与颜色共同传达，不仅依赖颜色。
- 今天的计划弱调突出，逾期使用克制的暖棕色，已完成与未开始保持低视觉重量。
- 标签、List 入口和返回链接支持键盘访问与明确焦点。
- 375px、768px 和 1440px 宽度下不产生水平溢出。

## 测试与验收

### 领域测试

- 复习节点按日期聚合，可生成「8 月 24 日：List 1、List 2」。
- 同日 List 排序与异常重复去重正确。
- `已完成`、`待复习`、`已逾期`、`未开始` 状态计算正确。

### 组件与路由测试

- 历史页默认显示「复习计划」，可切换到「全部 Lists」。
- 一览表展示全部日期、List 和状态。
- 每个历史 List 都有手动复习入口。
- 从历史手动复习今天到期的 List 会完成今天节点。
- 手动复习未到期或已完成的 List 不修改复习计划。
- 从历史进入后返回历史，从首页进入后返回首页。
- List 不存在时显示可恢复的空状态。

### 端到端验收

- 用户可在历史页看到按日期聚合的完整复习安排。
- 用户可从「全部 Lists」进入额外复习并返回历史页。
- 用户可从今天或逾期的计划项进入正式复习并刷新状态。
- 移动端与桌面端布局无水平溢出，主要交互可键盘操作。

## 非目标

- 不增加月历或日历视图。
- 不允许提前完成未来的复习节点。
- 不记录额外复习次数、时长或成绩。
- 不改变现有艾宾浩斯间隔或今日录入解锁规则。
