# 首页进度栏与导航融合设计

## 背景

首页使用夹板纸张背景，但当前进度栏跟随宽屏容器拉伸，标签与数字在部分视口下靠近或越出白色纸张的视觉安全区。Header 还使用向视口两侧无限铺开的高不透明米白背景，形成独立色带，与纸张纹理不协调。

## 目标

- 缩短首页进度轨道，并让标签、轨道、数字全部位于纸张安全区内。
- 弱化首页 Header 的覆盖层，让导航与纸张背景融合。
- 保持原有信息结构、背景图片和交互不变。
- 在 375px、768px、1440px 视口下保持可读且无横向溢出。

## 首页 Header

- 保留现有品牌、历史入口、分隔线和设置入口，不改变 Header 高度与 DOM 结构。
- 移除 `box-shadow: 0 0 0 100vmax ...` 和配套 `clip-path`，不再让 Header 背景横向铺满整个视口。
- Header 覆盖层限制在首页内容容器内，采用暖米白低透明背景，目标透明度为 52% 至 60%，使纸张纹理仍清晰可见。
- 底部分隔线进一步降低对比度，但继续提供导航区与学习状态区的层次边界。
- 导航文字和图标继续使用低饱和深灰绿色，并保持现有 hover、焦点和 44px 点击区域。

## 首页进度栏

- `.today-progress` 继续负责垂直留白和底部分隔线。
- `.progress-wrap` 在首页内设置 `width: min(100%, 840px)` 并水平居中，形成稳定的纸张安全区。
- 桌面端继续使用“今日进度 / 轨道 / 数字”单行三列布局。
- 缩小三列间距，使标签和数字靠近轨道，但不牺牲辨识度。
- 进度轨道继续使用 6px 高度、低饱和灰绿色底色和森林绿完成色。
- 移动端保持标签与数字在第一行、轨道在第二行；容器使用完整可用宽度，不设置固定像素宽度。

## 视觉原则

- 不新增卡片、阴影、图标或装饰。
- 不修改夹板纸张背景图片或其裁切方式。
- Header 与进度区依靠透明度、留白和细分隔线建立层次，而不是额外表面。
- 所有普通文字维持足够对比度，交互焦点样式保持可见。

## 验收标准

- 首页 Header 不再使用 `100vmax` 扩展背景或 `clip-path`。
- Header 背景能透出纸张纹理，且导航仍清晰可读。
- 首页进度栏最大宽度为约 840px，并在页面中居中。
- “今日进度”和计数不会落到白色纸张视觉边界之外。
- 375px、768px、1440px 浏览器测试无水平滚动。
- 内页 Header、背景图片、业务逻辑和进度数据不受影响。

## 非目标

- 不重新设计首页核心区域、主按钮或连续学习信息。
- 不修改 Header 的导航内容。
- 不生成或替换背景图片。
