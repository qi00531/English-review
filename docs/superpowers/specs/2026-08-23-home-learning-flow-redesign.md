# Word Journal 首页学习流重设计

## 目标

在不修改现有夹板纸背景图片的前提下，将首页改为克制的自适应单列学习流。页面只强调今日复习事实、当前任务和唯一可执行操作，避免 Hero、鼓励文案、数据卡片和装饰性元素。

## 视觉方向

- 使用低饱和深灰绿色与森林绿，延续现有纸张和手账气质。
- 中文状态文字采用 Editorial 风格 Serif 字体，字号 `clamp(28px, 3vw, 36px)`，字重适中。
- 页面依靠留白和位置建立层级，不新增卡片背景、徽章、插图或完成动画。
- 本次明确允许 Header、进度区和连续学习区使用非常浅的分割线；该要求覆盖之前“不使用细分割线”的偏好。
- `public/assets/clipboard-paper-background.png` 不重新生成、不编辑、不替换。

## 页面结构

### 顶部导航

- Header 高度约 `100px`，无卡片背景。
- 内容在应用最大宽度内左右展开；桌面端视觉 padding 为 `56–72px`，移动端收缩至 `20–24px`。
- 左侧为线性打开书图标和 Serif 字体 `Word Journal`。
- 右侧为“历史”、一条低对比度竖线和设置齿轮图标。
- 导航使用低饱和深灰绿色；Header 底部有一条非常浅的水平线。

### 今日进度栏

- 位于 Header 下方，横向占据页面主要宽度，上下保留充足但克制的 padding。
- 顺序固定为：`今日进度`、6px 高细进度条、`完成数 / 今日总数`。
- 未完成轨道使用浅灰绿色，已完成部分使用低饱和森林绿。
- 进度栏无卡片、标题和图标，底部有一条浅水平线。
- 今日总数为“当前仍待复习节点 + 今天已完成节点”。完成数为今天已完成节点数量。
- 当天原本没有复习任务时使用 `0 / 1` 作为空状态显示，避免无意义的 `0 / 0`。

### 核心学习区

- 核心区域采用单列、自适应高度、水平居中布局并保留大面积留白。
- 无待复习内容时只显示“今天的复习已经完成。”，不显示副标题、说明或鼓励性文案。
- 状态文字下方 `48–64px` 放置唯一主操作“记录今天所学 →”。
- 主按钮宽 `260–330px`、高 `64–72px`，森林绿背景、米白文字、轻圆角和极浅阴影；左侧为线性铅笔图标，右侧为箭头。
- Hover 只允许轻微颜色变化或上移 1px。

### 待复习状态

- 有待复习内容时，状态改为“今天还有 N 个 List 待复习”。
- 状态下方展示按到期顺序排列的紧凑 List 行，每行保留 List 编号、词数和进入复习的明确点击区域。
- 此状态不显示“记录今天所学”主按钮，也不显示第二个主操作；完成最后一个 List 后自动切换至完成态。

### 连续学习

- 靠近视口下方但不贴底，视觉优先级低于核心状态和 CTA。
- 内容为线性日历图标、`连续学习`、稍突出数字和`天`，左右各一条非常浅的线。
- 不使用 emoji、徽章、数据卡片或 Dashboard 形式。
- 连续天数依据历史 List 的 `createdDate` 计算：从最近一个有 List 的日期开始向前逐日计数，日期中断即停止；同一天多个记录只计一天。

## 自适应规则

- 桌面端核心区利用剩余视口高度垂直组织状态、CTA 和连续学习信息。
- 移动端进度栏允许标签与计数位于第一行、进度条位于第二行；信息顺序不变。
- 主按钮在窄屏使用可用宽度但不超过 330px。
- 待复习 List 增多时页面自然向下扩展，不使用固定高度裁切内容。
- 375px、768px 和 1440px 宽度下不得出现水平滚动。

## 数据与组件边界

- `buildTodayViewState` 负责从 Repository snapshot 派生待复习列表、今日进度和连续学习天数。
- 独立纯函数负责连续日期计算，便于测试时区、重复日期和日期中断。
- `Progress` 扩展为横向紧凑显示，不在业务页面重复进度结构。
- `TodayPage` 只根据派生状态渲染完成态或待复习态，不直接读取数据库。
- `AppShell` 只调整 Header 结构和语义，不改变现有导航目标。

## 验收标准

- 首页背景图片文件内容与 Git blob 保持不变。
- 完成态没有副标题、Eyebrow、勾选图标、动画、徽章、插图或鼓励文案。
- 页面仅有一个 Primary CTA；待复习时该 CTA 不出现。
- Header、进度栏、完成状态、CTA、连续学习信息的视觉顺序与需求一致。
- 连续学习算法和今日进度有单元测试覆盖。
- 键盘导航、焦点样式和 WCAG AA 对比度保持有效。
- 单元测试、类型检查、生产构建和 Playwright 浏览器测试全部通过。
