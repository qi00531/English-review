# 固定导航与历史页精简设计

## 背景

当前导航位于普通文档流中，页面滚动后会离开视口。React Router 切换路由时没有统一重置窗口滚动位置，因此用户从已滚动的页面进入“历史”后，新页面可能继续停留在原滚动高度。导航中的“历史”链接也只有文字变色反馈，与“设置”的圆形悬停反馈不一致。历史页顶部还保留了 `Archive`、重复的“历史”标题和说明文字，占用了首屏空间。

## 目标

- 导航在所有页面固定于浏览器顶部，滚动时始终可见。
- 页面切换后自动回到顶部，避免新页面继承旧路由的滚动位置。
- “历史”与“设置”使用一致的悬停容器、背景反馈和点击区域。
- 删除历史页顶部的 `Archive`、“历史”和“查看复习安排，或回到任意 List 再练一次。”。
- 保持现有纸张背景、导航位置、品牌样式和历史页业务功能不变。

## 导航结构与定位

- `.site-header` 使用固定定位，位于视口顶部并保持现有统一视口宽度。
- 导航的左右坐标继续独立于各页面内容容器，首页、历史、设置和复习页之间不发生横向跳动。
- Header 默认保持透明，不增加常驻卡片背景或圆角。
- Header 使用足够高的层级，确保滚动内容不会盖住导航。
- 页面主内容增加与 Header 高度对应的顶部空间，避免内容被固定导航遮挡。
- 桌面端继续使用 100px 导航高度，移动端继续使用 88px 导航高度。

## 导航视觉与交互

- `Word Journal` 的书本图标、Serif 品牌字和深灰绿色保持不变。
- “历史”和“设置”共享 `.nav-action` 状态规则：点击区至少 44px 高，悬停时使用相同的低饱和灰绿色背景与森林绿色前景。
- “历史”保留适合文字链接的 9px 轻圆角和横向内边距；“设置”保留 44×44px 圆形轮廓。二者形状服从内容，但悬停反馈完全一致。
- “历史”仍显示完整文字，不改变为图标。
- “历史”和“设置”悬停时使用相同背景色与文字颜色；当前页面状态继续以森林绿色表达。
- Header 默认不显示实体背景；鼠标进入 Header 或页面已发生滚动时显示已确认的轻微暖灰绿色阴影。
- 阴影只用于区分固定导航与滚动内容，不增加位移、卡片边框或强烈磨砂效果。

## 路由滚动行为

- 在应用壳层中监听 `pathname` 和查询参数变化。
- 每次实际路由位置变化后调用 `window.scrollTo({ top: 0, left: 0, behavior: 'auto' })`。
- 使用即时复位，不使用平滑滚动，避免新页面出现从旧位置向上滑动的视觉噪声。
- 同一路由内普通交互不触发滚动复位。
- Header 根据窗口 `scrollY > 0` 设置滚动态类；组件卸载时移除滚动监听。

## 历史页精简

- 删除历史页 `<header className="section-heading">` 整组内容。
- 历史页直接以“复习计划 / 历史 List”标签切换区作为首个主要内容。
- 保留标签语义、空状态、复习计划、历史 List、编辑、删除和手动复习功能。
- 调整历史页顶部 padding，使标签区与固定导航之间保持清晰但克制的留白。

## 可访问性

- 导航仍使用 `<header>` 和带 `aria-label="主要导航"` 的 `<nav>`。
- “历史”仍以可读文字呈现，“设置”继续保留可访问名称。
- 两个入口的点击区域均不小于 44×44px。
- 键盘焦点继续使用现有 `:focus-visible` 样式，不依赖 hover 或阴影表达焦点。
- 固定导航不遮挡跳转后的主要内容和 skip link。

## 测试与验收

- 组件测试验证历史页不再渲染 `Archive`、重复标题和说明文字。
- 组件或样式测试验证“历史”与“设置”共享 `.nav-action` 状态类和相同悬停颜色。
- 组件测试验证路由变化调用即时 `scrollTo`。
- 浏览器测试从已滚动页面点击“历史”，确认新页面 `scrollY` 为 0。
- 浏览器测试确认滚动时 Header 仍位于视口顶部且导航入口可见。
- 375px、768px 和 1440px 下均无横向溢出，页面内容不被 Header 遮挡。
- 背景图片哈希保持不变。

## 非目标

- 不修改纸张或夹子背景图片。
- 不重做历史页的标签、计划表或 List 内容。
- 不修改导航文案、路由地址或业务数据。
- 不引入新的导航组件库、滚动动画或复杂玻璃效果。
