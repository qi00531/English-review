# English Review 产品设计规格

## 1. 产品目标

English Review 是一款面向个人使用的桌面网页工具。用户每天录入新学到的英语单词或短语，工具自动补全学习材料，并按固定遗忘曲线安排复习。

产品的核心不是增加学习内容，而是建立一个明确、可完成的闭环：先完成所有到期复习，再开始当天的新学习。

第一版不包含账号、云同步、移动端专项设计、浏览器通知、积分、排行榜或连续签到。

## 2. 核心概念

### 2.1 List

- 同一个浏览器自然日录入的所有词条归入同一个 List。
- List 按首次创建顺序命名为 `List 1`、`List 2`，并保存实际创建日期。
- 同一天允许分多次向当天的 List 追加内容，不限制新增数量。
- 每个 List 包含多个单词或短语，并共享同一套复习节点。

### 2.2 固定复习节点

List 创建日为 D0，复习节点固定为：

- D+1
- D+2
- D+4
- D+7
- D+15
- D+30

复习结果不动态调整后续日期。每次完成只推进当前固定节点。

### 2.3 严格解锁规则

- 打开首页后，优先展示当天到期和已经逾期的 Lists。
- 逾期任务不会消失或跳过，按最早到期时间优先排列。
- 当天所有到期和逾期 Lists 都完成后，才解锁当天的录入入口。
- 完成状态以整个 List 为单位，不要求逐词打卡。

## 3. 核心用户流程

### 3.1 今日复习

1. 用户打开网页。
2. 首页展示今日全部待复习 Lists、剩余数量和整体进度。
3. 用户逐个进入 List，可在单词模式与表格模式之间切换。
4. 用户完成整个 List，并推进该 List 的固定复习节点。
5. 所有待复习 Lists 完成后，首页解锁今日录入。

### 3.2 今日录入

1. 用户逐条输入，或按一行一条批量粘贴英文单词和短语。
2. 系统批量查询词典并调用 AI 补全内容。
3. 页面展示生成预览；用户可以修改任意词条。
4. 用户可一键保存全部成功词条。
5. 内容写入当天唯一的 List，并生成六个固定复习节点。

### 3.3 历史管理

- 用户可以按 List 浏览历史内容和各节点完成情况。
- 用户可以编辑词条内容。
- 删除 List 前必须二次确认。
- 设置页提供 JSON 导出备份和导入恢复。

## 4. 词条内容模型

每个单词或短语保存：

- 英文原文
- 美式音标和美式发音资源
- 英式音标和英式发音资源
- 多个主要中文义项，不只保留最高频的一个意思
- 一句对应最常见义项的英文例句
- 例句的中文翻译
- 内容来源、生成状态和最后编辑时间

发音默认使用美式，允许切换英式。优先采用词典真人音频；词典缺失时使用语音合成。

## 5. 复习体验

### 5.1 展示模式

单词模式和表格模式均支持：

- 完整：展示英文、中文义项和英文例句
- 英文：隐藏中文义项
- 中文：隐藏英文单词及音标

例句中文翻译默认隐藏。点击英文例句区域直接展开或收起翻译，不显示“显示中文翻译”之类的提示按钮。

### 5.2 单词模式

- 一次只展示一个词条。
- 进入词条后持续循环播放当前发音，直到切换到另一个词条、暂停播放、切换播放模式或离开页面。
- “上一个”和“下一个”固定在页面底部中央，位置不随内容长度变化。
- “完成复习”只在当前 List 的最后一个词条页面出现。

### 5.3 整组自动播放

- 单词模式提供“播放本组”。
- 开启后，系统按 List 顺序播放全部词条，并在结束后从第一条继续循环。
- 当前词循环和整组自动播放互斥，任何时刻只能存在一个活动音频源。
- 切换单词、模式、List 或路由时，旧音频必须立即停止。

### 5.4 表格模式

- 一次展示整个 List，不展示 List 日期。
- 点击任意词条所在的整行即可播放该词发音。
- 当前播放行通过背景状态和文字或图形标识反馈，不能只依赖颜色。
- “完成复习”位于页面右上区域。
- 英文或中文模式通过隐藏对应列实现，不能留下无意义空列。

### 5.5 完成操作

- 完成以整个 List 为单位。
- 完成后提供安静、短暂的成功反馈，不使用庆祝弹窗。
- 完成后提供数秒撤销入口，避免误触造成复习节点错误推进。

## 6. 页面结构

### 6.1 今日首页

首页只回答“今天需要做什么”：

- 今日剩余待复习 List 数量
- 总体完成进度
- 按到期时间排列的待复习 Lists
- 今日录入的锁定或解锁状态

历史和设置属于次级入口，不与今日任务竞争视觉注意力。

### 6.2 录入与生成预览

- 支持单条输入和多行批量输入。
- 输入只要求英文，不要求用户先填中文。
- 使用明确的字段标签和持久辅助文字，不以占位符代替标签。
- 生成过程逐条显示状态，成功内容可以先预览，失败内容不会阻塞其他词条。
- 支持单条重试、全部重试、手动修改和一键保存成功内容。

### 6.3 历史页

- 以 List 为主要浏览单位。
- 展示创建日期、词条数量、当前复习节点和完成记录。
- 支持进入 List 查看和编辑内容。
- 不设计成数据 Dashboard，不加入无助于复习决策的统计图表。

### 6.4 设置页

- AI 服务连接状态
- 默认发音口音
- JSON 导出备份
- JSON 导入恢复
- 本地数据说明和清除数据入口

## 7. 视觉与行为设计系统

### 7.1 设计方向

采用克制的编辑式手账风格，以专注单页为核心。手账感来自暖色纸张表面、字体、留白和排版节奏，不使用细分割线、贴纸、胶带、emoji、卡片网格或装饰性涂鸦。

界面需要有明确的视觉观点，但不能以装饰强度制造辨识度。记忆点是“像翻开一本安静的个人词汇册”。

### 7.2 色彩与字体

- 大面积使用暖纸白背景。
- 正文使用高对比墨黑绿。
- 苔藓绿只用于当前状态、焦点和主要操作。
- 陶土色仅用于警告与需要注意的异常。
- 功能状态必须同时提供图形或文字提示，不能只依赖颜色。
- 英文单词和主要标题使用有书卷感的衬线字体。
- 中文正文和操作控件使用高可读无衬线字体。
- 移动窄屏正文不小于 16px；桌面端正文保持舒适阅读尺寸。

### 7.3 布局规则

- 通过留白、字号、字重和极轻的表面色差分组，不使用细分割线。
- 使用 4/8 像素间距体系，建立稳定的垂直节奏。
- 每个页面只有一个主要目标和一个主要操作。
- 交互控件位置稳定，不因内容长短产生跳动。
- 桌面内容区域控制阅读宽度；窄屏不产生横向滚动。

### 7.4 控件规则

- “完整 / 英文 / 中文 / 表格”使用轻量文字导航和当前项标识，不使用成排胶囊按钮。
- “完成复习”使用清晰但克制的页眉操作，不使用厚重、高饱和的大按钮。
- 所有可点击区域至少 44×44px。
- 结构性图标使用同一套 SVG 线性图标，不能使用 emoji。
- hover、按下、焦点、禁用和加载状态必须清晰且不造成布局位移。

### 7.5 行为心理学原则

- 降低选择负担：首页先呈现到期任务，不让用户在多个入口间决策。
- 利用目标梯度：持续展示“还剩几个 List”，让接近完成的进度清晰可见。
- 渐进披露：例句翻译、次要设置和详细历史按需展开。
- 保持空间稳定：导航与主要操作固定位置，减少重复寻找控件的认知成本。
- 提供自主控制：任何自动音频都必须能立即暂停。
- 避免动机替代：不使用积分、排行榜和签到等与真实复习目标竞争的奖励。
- 严格锁定规则来自用户明确选择；页面应清楚解释未解锁原因，不能让入口无提示消失。

### 7.6 动效与无障碍

- 动效只表达状态变化和空间连续性，时长以 150–300ms 为主。
- 支持 `prefers-reduced-motion`，减少动态模式下仍可完整操作。
- 正文对比度达到 WCAG AA；焦点轮廓清晰。
- 键盘可以完成导航、模式切换、播放、翻页和完成 List。
- 图标按钮提供可访问名称，动态状态通过可访问实时区域播报。

## 8. 技术与数据架构

### 8.1 浏览器端

- 使用 IndexedDB 保存 Lists、词条、复习计划、完成记录、草稿和用户设置。
- 不把词汇历史存入普通缓存或仅依赖 `localStorage`。
- 音频资源默认只保存 URL 和必要元数据，不把在线音频文件长期写入数据库。
- 数据库必须支持版本迁移，并在升级失败时保留原数据和恢复路径。

### 8.2 内容生成服务

采用“在线词典 + AI”混合方案：

1. 词典服务优先查询音标、真人发音和基础词义。
2. AI 统一补全和整理多个主要中文义项。
3. AI 为最常见义项生成一句自然英文例句及中文翻译。
4. 词典无法覆盖短语时，由 AI 补全全部字段，发音使用语音合成兜底。

正式部署使用轻量服务端代理保存 API Key。浏览器只向代理发送当前待补全的英文内容，不上传历史 Lists、复习状态或其他本地数据。服务端不应记录用户词汇正文。

### 8.3 日期与排期

- 使用浏览器本地时区确定自然日。
- 数据库存储规范化时间戳和计算复习日期所需的本地日期键。
- 排期以日历日计算，而不是简单增加 24 小时，避免夏令时或时区偏移导致日期错误。

## 9. 异常与恢复

- 网络不可用：保留输入草稿，允许稍后重试；历史复习仍可离线使用。
- 词典失败：转交 AI 补全，并标明发音采用语音合成。
- AI 部分失败：成功词条保留预览，失败词条展示原因和恢复操作。
- 音频失败：停止加载状态，提供重试并允许继续浏览，不阻塞完成 List。
- 导入失败：在写入前完成格式和版本校验，提示具体错误，不修改现有数据。
- 导入覆盖：展示影响范围并要求确认；覆盖前自动生成一次可下载备份。
- 数据被浏览器清除：应用无法自行恢复，只能通过用户此前导出的 JSON 恢复；设置页必须明确说明这一限制。

## 10. 验收标准

### 10.1 业务逻辑

- 固定六节点排期在跨月、跨年和本地时区变化时计算正确。
- 到期和逾期 Lists 未全部完成时，录入入口保持锁定并说明原因。
- 同一天多次保存只写入同一个 List。
- 完成和撤销能正确更新当前节点及首页解锁状态。

### 10.2 内容生成

- 仅输入英文即可生成完整预览。
- 单词和短语均能保存多个主要中文义项。
- 每个词条只生成一句对应最常见义项的例句。
- 批量生成允许部分成功、部分失败，并能分别恢复。

### 10.3 音频

- 单词循环、整组播放和表格行播放互斥。
- 切换词条、模式、List 或页面时旧音频立即停止。
- 美式和英式切换后，当前播放资源同步更新。
- 浏览器阻止首次自动播放时，页面明确提供一次启动操作。

### 10.4 界面与可访问性

- 单词模式只在最后一词显示完成操作；表格模式在右上区域展示。
- 两种复习视图均支持完整、英文和中文模式。
- 点击例句直接切换翻译；点击表格整行直接播放发音。
- 页面不使用细分割线、装饰 emoji、卡片堆叠或 Dashboard 布局。
- 375px 窄屏到常见桌面宽度均无横向溢出。
- 键盘操作、焦点顺序、对比度、点击区域和减少动态模式通过检查。

### 10.5 数据可靠性

- IndexedDB 关闭浏览器后仍能恢复完整状态。
- JSON 导出后可在空数据库中完整导入。
- 无效或旧版本备份不会破坏现有数据。
- 数据库升级和 AI 请求失败不会丢失未保存草稿。
